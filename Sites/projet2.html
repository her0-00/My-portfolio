Application R Shiny - Criminalité USA

Description du projet

50 États analysés
7 Types de crimes
100% Interactif

Ce projet explore les taux de criminalité aux États-Unis à partir des données publiques fournies par le ministère de la Justice et le FBI.

Défi technique

Créer une application web interactive permettant l'exploration intuitive de millions de données criminelles avec analyses multivariées en temps réel

Les données couvrent les 50 États et se répartissent en deux grandes catégories :

  • Crimes contre les biens : cambriolages, larcins et délits automobiles.
  • Crimes violents : agressions, meurtres, viols et vols qualifiés.

Notre objectif était de concevoir une application R Shiny permettant une exploration intuitive et interactive de ces données.

Architecture technique & Fonctionnalités

Stack technique

R Shiny ggplot2 plotly leaflet DT

Points clés

  • Importation et nettoyage des données : automatisation du traitement des données brutes.
  • Visualisation dynamique : graphiques interactifs et cartes choroplèthes pour comparer les États.
  • Filtres avancés : exploration des crimes par type, localisation et variables socio-économiques.
  • Modélisation statistique : analyse des corrélations entre criminalité et facteurs économiques.
  • Analyse multivariée : ACP et AFC pour identifier les caractéristiques clés et leurs relations.
  • Interface intuitive : tableau de bord ergonomique facilitant l'analyse.

Innovation clé

Implémentation d'algorithmes de clustering dynamique permettant de regrouper automatiquement les États selon leurs profils criminologiques
