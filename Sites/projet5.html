The Resume Intelligence Engine

75% des candidatures sont rejetées par des bots avant qu'un humain ne les lise.

Contexte & Problématique

Les systèmes ATS (Applicant Tracking Systems) comme Workday, Taleo ou iCIMS filtrent automatiquement les CV avant toute lecture humaine. Un CV mal structuré ou sans les bons mots-clés est éliminé en quelques secondes. RIIS résout ce problème avec un pipeline IA complet : audit forensique, réécriture intelligente et génération de PDF optimisés ATS.

32 Thèmes PDF premium
3 Providers IA (Groq, Mistral, Gemini)
< 2s Analyse IA (Groq LPU)
10 Thèmes avec photo de profil

Défi principal

Construire un système dual-agent (Auditeur + Architecte) capable d'analyser sémantiquement un CV, de le comparer à une offre d'emploi, et de générer un PDF pixel-perfect lisible par les ATS — le tout en quelques secondes.

Architecture Technique

RIIS fonctionne comme un pipeline dual-agent avec un frontend Next.js et un backend Python indépendant, communicant via des API routes.

Stack complète

Next.js React TypeScript Python 3.11 Groq (Llama-3.3-70b) Mistral AI Google Gemini ReportLab pdfminer.six Pillow OpenCV Docker Render

Extracteur

PDF Engine

Fonctionnalités Clés — v4.0

Workflow

Coller la description de l'offre ciblée après l'upload du CV pour une analyse immédiate : score ATS, keywords manquants, réécriture optimisée et export PDF.

Audit Forensique ATS

Analyse précise avec score 0-100, probabilité de passage et verdict marché :

  • Détection des keywords techniques et soft skills manquants
  • Évaluation de la densité de contenu vs niveau de séniorité requis
  • Analyse psychologique recruteur — le "Shadow Profile" présenté aux hiring managers
  • Benchmarking de valeur marché et identification du "Salary Gap"

Réécriture IA Intelligente

3 providers au choix — Groq, Mistral AI ou Google Gemini :

  • Boost Mode — enrichissement des expériences avec les accomplissements pertinents pour le poste
  • Dual Language — traduction et optimisation FR ↔ EN
  • Live Editor — cliquer sur n'importe quelle partie du PDF pour éditer directement
  • Injection sémantique de keywords contextualisés à l'offre

PDF Engine — 32 Thèmes Premium

Les CV Canva/Design échouent les ATS car non lisibles par les machines. ReportLab dessine aux coordonnées exactes :

  • 16 thèmes standard — de "Tech Grid" à "SOTA Luxury" (champagne gold ultra-premium)
  • 10 thèmes avec photo — "Executive Portrait", "Modern Profile", "Creative Vision"...
  • 6 thèmes ATS-optimized — lisibilité maximale pour les systèmes de parsing
  • Studio de personnalisation : couleurs d'accent, typographie, fonds, bordures photo
  • 100% text-extractable avec mapping Unicode correct — génération vectorielle pure

Photo de Profil Intégrée

Upload et intégration de photo professionnelle dans les 10 thèmes photo-enabled :

  • Détection automatique du visage et centrage intelligent
  • Recadrage smart au format carré, optimisation qualité impression
  • Rendu circulaire ou carré selon le thème
  • Couleur de bordure personnalisable — traitement local, jamais stocké serveur

Déploiement Docker + Render

Infrastructure de production complète :

  • Dockerfile multi-stage : Node 20 + Python 3.11 + Playwright Chromium
  • render.yaml pour déploiement automatisé sur Render
  • Zero data retention — traitement en mémoire uniquement
  • Clés API côté client (localStorage) — jamais loggées serveur
  • Support Groq, Mistral et Google AI via variables d'environnement
