Contexte & Problématique

Les systèmes ATS (Applicant Tracking Systems) comme Workday, Taleo ou iCIMS filtrent automatiquement les CV avant toute lecture humaine. Un CV mal structuré ou sans les bons mots-clés est éliminé en quelques secondes. RecruitIQ résout ce problème avec un pipeline IA complet : audit forensique, réécriture intelligente et génération de PDF optimisés ATS.

v4.0 Version actuelle
15 Thèmes PDF premium
< 2s Analyse IA (Groq LPU)

Défi principal

Construire un système dual-agent (Auditeur + Architecte) capable d'analyser sémantiquement un CV, de le comparer à une offre d'emploi réelle scrapée en temps réel, et de générer un PDF pixel-perfect lisible par les ATS — le tout en moins de 30 secondes.

Architecture Technique

RecruitIQ fonctionne comme un pipeline dual-agent avec un frontend Next.js et un backend Python indépendant, communicant via des API routes.

Fonctionnalités Clés — v4.0

Workflow Dual-Path

Après l'upload du CV, deux parcours au choix :

  • « J'ai une offre » — coller la description, analyse immédiate CV vs offre, score ATS + keywords manquants, réécriture optimisée, export PDF
  • « Cherche des offres » — extraction automatique des keywords du CV par Groq, scraping intelligent WTTJ + HelloWork, scoring IA de pertinence (0-100) pour chaque offre, sélection → audit → réécriture → PDF

Audit Forensique ATS

Analyse précise avec score 0-100, probabilité de passage et verdict marché :

  • Détection des keywords techniques et soft skills manquants
  • Évaluation de la densité de contenu vs niveau de séniorité requis
  • Analyse psychologique recruteur — le "Shadow Profile" présenté aux hiring managers
  • Benchmarking de valeur marché et identification du "Salary Gap"

Réécriture IA Intelligente

Propulsé par Groq (Llama-3.3-70b) — analyse sub-seconde grâce au LPU :

  • Boost Mode — enrichissement des expériences avec les accomplissements pertinents pour le poste
  • Dual Language — traduction et optimisation FR ↔ EN
  • Live Editor — cliquer sur n'importe quelle partie du PDF pour éditer directement
  • Injection sémantique de keywords contextualisés à l'offre

PDF Engine — 15 Thèmes Premium

Les CV Canva/Design échouent les ATS car non lisibles par les machines. ReportLab dessine aux coordonnées exactes :

  • De "Tech Grid" (style dev épuré) à "Luxury Serif" (exécutif)
  • Studio de personnalisation : couleurs d'accent, échelles de police, fonds
  • 100% text-extractable avec mapping Unicode correct
  • Génération vectorielle — aucune image floue

Job Scraping Intelligent

Playwright headless pour les sites JS-rendered :

  • Timeouts intelligents : 15s/page, 30s total
  • Rate limiting respectueux : 2s entre sites, max 10 offres/site
  • Déduplication automatique des résultats
  • Sources : WTTJ, HelloWork (architecture extensible)

Déploiement Docker + Render

Infrastructure de production complète :

  • Dockerfile multi-stage : Node 20 + Python 3.11 + Playwright Chromium
  • render.yaml pour déploiement automatisé sur Render
  • Zero data retention — traitement en mémoire uniquement
  • Groq API key côté client (localStorage) — jamais loggée serveur
